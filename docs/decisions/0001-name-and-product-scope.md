# ADR-0001: Working name and product scope

**Status:** Accepted for repository scaffold; name remains unresolved for public release.
**Date:** 2026-09-07

## Context

The project was initially called “VeilCheck.” Public web research identified a privacy protocol marketing a “Veil Check+” private-payment product. The names operate in related privacy/blockchain terminology and could create confusion or trademark risk.

The project also risked being described too broadly as a privacy scanner or audit platform.

## Decision

1. Use **VeilCheck** only as a working/internal project name.
2. Describe the product generically as a **privacy-boundary CI gate** until a name-clearance decision is complete.
3. Position the product as policy-driven checks for existing Vela, zkVerify, and Solidity integrations.
4. Do not claim audit, certification, compliance, complete privacy verification, or product-name exclusivity.

## Consequences

- Repository documentation carries an explicit name-status note.
- Branding, domain purchase, incorporation, and marketplace publication are blocked until clearance.
- The product scope remains focused enough for a Category 3 public-good grant and can be evaluated by concrete fixtures and pilots.
